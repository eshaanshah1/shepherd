# v2 M0 — implementation plan (skeleton)

Goal (from [`2026-08-06-ade-v2-core-design.md`](../specs/2026-08-06-ade-v2-core-design.md) §7 M0):
`v2/` monorepo; Electron boots; one xterm.js view attached to a main-process
node-pty session; splits via ported `SplitTree`; dev/prod isolation;
single-instance lock. **No extension host yet** (that's M1) — but every M0
module sits where M1 expects it.

## Constraints (bind the executor)

- Everything under `v2/`; nothing outside it except this plan's checkboxes.
  The Swift app is reference material, never touched.
- pnpm workspaces + TS project references. Electron + electron-vite + React.
  `@xterm/xterm` (new scoped name). `node-pty` **must be rebuilt against
  Electron's ABI** (`@electron/rebuild` in postinstall) — the classic silent
  crash. If sandbox/network blocks Electron's binary download, stop and
  report — don't fight it.
- Import boundaries lint-enforced from day one: `packages/core` imports
  stdlib + node-pty only (no electron, no react); `packages/sdk` is types +
  pure helpers; only `packages/platform/darwin` touches OS APIs; React only
  in `packages/app`.
- Pure ports are **tests-first**, translated from the Swift originals:
  `spike/seam1/Sources/SplitTree.swift` + `Tests/SplitTreeTests.swift`
  (~331 lines, dependency-free), and a real circular-buffer `PtyRing`
  (replay semantics per `spike/seam1/Sources/` PtyBroker; O(1) append/evict).
- Vitest for tests. A phase is done only when `pnpm -r test` and
  `pnpm -r typecheck` pass **and the test count moved** for ported suites.
- No `Date.now()` in core logic — `Clock` injected (SDK pattern).
- Commit at each phase boundary on this branch (`fable-electron-refactor`),
  message style `feat(v2): …`, with the project Co-Authored-By line.

## Modules

1. **`packages/core/session`** — `SessionHost`: registry keyed by
   `SessionID` (uuid), `create({cwd, command?, env?, cols, rows})`,
   `write/paste`, `resize`, `kill`, `onExit`; per-session `PtyRing`
   (256 KB); `attach()` → replay-then-live byte stream; env injection seam
   (`onWillCreate` hook array) present but with no consumers yet.
2. **`packages/core/layout`** — `SplitTree` port: `Pane`, `SplitAxis`
   (`.row`/`.column` with v1's exact vocabulary — see the ADR 0012 gotcha),
   `SplitNode` ops (`split/updatePane/setRatio/frames/neighbor/closing`),
   serializable. Pure; ported tests pass.
3. **`packages/sdk`** — types only for now: `SessionID`, `Caller`, `Clock`,
   `Disposable`, result types. (Placeholder for M1's real surface.)
4. **`packages/design-tokens`** — the Flock tokens as data (named palette,
   dark canonical + light derived, cell metrics) with two generators:
   CSS variables and an xterm theme object. Values from the approved mock.
5. **`packages/app`** — main: create window, `SessionHost` wiring, IPC
   channels (`session:create/attach/write/resize`, chunked bytes), preload
   exposing a typed bridge; single-instance lock **before** any socket/
   registry work; dev/prod isolation (`app.setPath('userData', …dev)` +
   build-time `IS_DEV` constant, per the review's recipe). Renderer: React
   shell rendering the SplitTree (recursive flex, hairline dividers), each
   leaf an `@xterm/xterm` instance attached over the bridge; keys ⌘D /
   ⌘⇧D / ⌘W / ⌘⌥-arrows minimal; tokens CSS applied (warm ink, mono).
   **Terminal instances are created/destroyed by explicit registry calls
   keyed by pane id — a React unmount must never kill a session** (the v1
   root finding, now cheap to honor).
6. **`extensions/`** — empty dirs + READMEs naming their M2/M3 occupants.

## Phase seed (Opus refines)

P0 env+scaffold → P1 pure ports (layout, ring) → P2 session host + IPC →
P3 renderer (xterm view, splits, tokens) → P4 isolation + lock + smoke.
Each phase ends green (`test` + `typecheck`), committed, with a 3-line
summary and an explicit `deviation` field (empty = none).

## Out of scope for M0

Extension host, commands registry, event ingress, attention, tasks, sheep
artwork, packaging/signing, Playwright. Resist all of them.
